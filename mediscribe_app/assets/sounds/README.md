# Ringtone File Required

Please add a ringtone MP3 file here for incoming call notifications.

## How to Add:

1. Download or create a ringtone MP3 file (3-5 seconds, loop-friendly)
2. Rename it to: `ringtone.mp3`
3. Place it in this directory: `assets/sounds/ringtone.mp3`

## Recommended Sources:

- **Free Sounds:**
  - https://freesound.org/ (search "phone ringtone")
  - https://www.zapsplat.com/ (free account required)
  - https://pixabay.com/sound-effects/

- **Generate Online:**
  - https://bigsoundbank.com/
  - https://www.myinstants.com/

## File Requirements:

- Format: MP3
- Duration: 3-5 seconds (will loop automatically)
- Size: < 500KB
- Quality: 128kbps is sufficient

## Alternative:

If you don't have an MP3 file yet, the app will still work but won't play a ringtone sound. You can add it later.

---

**Temporary Solution:** You can also use any existing MP3 file and rename it to `ringtone.mp3` for testing purposes.
